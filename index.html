How do I get the file from Jira?

In Jira, open the issue search (Filters → Search work items, or "View all issues"). Filter to your sprint, for example sprint in openSprints(). Then use Export → Export CSV (all fields). Menu names vary a little between Jira versions.

The page reads these columns when they're there: Issue key, Summary, Issue Type, Status, Status Category, Assignee, Created, Updated, Resolved, Sprint, Story Points and Flagged.
